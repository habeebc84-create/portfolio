# C. Habeeb — AI & ML Developer Portfolio

Dark, glassmorphism portfolio built with React + Vite, Tailwind CSS, GSAP + ScrollTrigger and Lenis smooth scrolling — the default stack from Habeeb's website toolkit (Tailwind + GSAP + Lenis first; Three.js only for a 3D hero, not used here).

## Design system (from the UI/UX Pro Max approach)
- Product type: personal portfolio / personal brand
- Style: Minimalism, dark mode, subtle glassmorphism, restrained gradients
- Background: #070b14 · Text: #e6edf7 · Accent: cyan #22d3ee + violet #a78bfa (used sparingly)
- Typography: Space Grotesk for headings, Inter for body
- Motion: Lenis smooth scroll, GSAP fade-up on scroll entry, gentle floating hero orbs, hover lift on project cards
- Responsive: mobile-first, 375px / 768px / 1024px / 1440px

## Run locally
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```

## Deploy
Import this repo on Vercel with the Vite preset, or publish with GitHub Pages from the `dist` output after `npm run build`.
